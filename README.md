### Projetos em destaque

#### [poc-gke-lab](https://github.com/jorgediasdsg/poc-gke-lab)
Laboratório DevOps completo simulando uma migração de Cloud Run para GKE.

O projeto junta Terraform, Ansible, Kubernetes local com kind, Helm, FastAPI, PostgreSQL, React, Argo CD, GitHub Actions e Kong Ingress Controller.

É o projeto que melhor representa meu momento atual: infraestrutura, aplicação, CI/CD, GitOps e operação olhando para o mesmo fluxo.

#### [fedora-bootstrap-ansible](https://github.com/jorgediasdsg/fedora-bootstrap-ansible)
Automação com Ansible para preparar uma workstation Fedora de desenvolvimento.

A ideia é simples: ambiente reproduzível, menos configuração manual e mais velocidade para voltar a produzir.

#### [pdf-expert](https://github.com/jorgediasdsg/pdf-expert)
Serviço em Go para análise de arquivos PDF.

Projeto criado para mostrar evolução real de backend: do script simples para uma estrutura com camadas, testes, validação, métricas, Swagger/OpenAPI e separação de responsabilidades.

#### [ultimate-ttt](https://github.com/jorgediasdsg/ultimate-ttt)
Jogo da velha avançado feito com React, com documentação de decisões e espaço para evolução futura com backend em Go, multiplayer e bot.

#### [guesses](https://github.com/jorgediasdsg/guesses)
Jogo de adivinhação em Go usando Clean Architecture e Strategy Pattern.

Projeto pequeno, mas útil para demonstrar separação de responsabilidades, injeção de dependências e testabilidade.
